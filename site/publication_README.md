# Static publication bundle

site/index.html is source-controlled. site/dist/ is generated by make site and
is the self-contained directory to hand to a static host.

Inputs copied into the bundle are the manuscript and essay sources, citation
metadata, reproducibility/publication documentation, Figure 1 assets, and the
machine-readable Figure 1 provenance manifest, both license notices, and
paper/main.pdf. The bundle does not run model inference, download data, or
infer publication metadata.

The landing page links to the bundled relative PDF at paper/main.pdf. Repository
software is MIT-licensed; original authored content is CC BY 4.0. Third-party
datasets, frozen external artifacts, model outputs, and material with its own
terms are excluded from those grants.
